# AGENTS.md - RTIP formose branch

## Project goal

Replicate the formose-reaction RTIP-MD study (JACS Au 2026, 6, 922) using a
Python/JAX port of the upstream Rust RTIP-MD algorithm, with DeePMD-kit as
the real PES provider.  This branch (`formose/replicate`) intentionally
contains only the upstream-consistent algorithm: no reaction-coordinate
bias (RCMD), no ic5c02384 workflow, no size-scaling / oscillation /
early-stopping engineering.

## Repository layout (rules)

```
rtipmd/jax/            Python + JAX implementation of RTIP-MD
  src/rtip_jax/        Package source
  tests/               pytest suite
  README.md, USAGE_ZH.md
molecules/             Small-molecule XYZ library (formose species)
formose/               Formose replication workflow
  data/                Inputs only: SI structures, Table S1, initial cells
  runs/<case>/         Results only: one directory per MD case (see below)
  runs/_archive/       Discontinued / exploratory runs, kept for reference
  tune/<scan-case>/    Parameter tuning scans (regenerable, never committed)
  microkinetics/       Microkinetic ODE model + its runs/
  plots/               Report figures generated by plots.py (committed)
logs/slurm/            All slurm stdout/stderr (slurm-*.out / slurm-*.err)
```

### Slurm logs (hard rule)

* Every slurm job writes its stdout/stderr to `logs/slurm/` - never to the
  repo root, a code directory, or `formose/`.
* `formose/run_formose.slurm` already follows this:
  `#SBATCH -o logs/slurm/formose-%j.out` / `-e logs/slurm/formose-%j.err`.
* Logs are git-ignored and regenerable; delete old ones freely.  The
  directory is kept alive by the committed `logs/slurm/.gitkeep`.

### Result files (hard rule)

Every MD run writes to `formose/runs/<case>/`, where `<case>` is a short
snake_case name (`seed0`, `seed1`, `seed2`, `r2pair`, `r5pair`, ...).  A
case directory always contains the same fixed file set:

```
formose/runs/<case>/
  rtip.out                 CLI stdout: scalars + per-step progress
  rtip.pdb                 Trajectory (MD frames)
  rtip_decreasing_steps    RTIP state-machine history (Growing/Reducing/Off)
  bond_events.csv          Bond-event analysis (paper monitoring scheme)
  acceptance_report.md     Acceptance verdict vs paper criteria
```

* Inputs stay in `formose/data/`; never mix input cells into `runs/`.
* Dead-end / superseded runs move to `formose/runs/_archive/` instead of
  accumulating in `runs/`.
* Parameter scans go to `formose/tune/<scan-case>/` (git-ignored).
* Figures go to `formose/plots/` and ARE committed (report artifacts).
* Microkinetics outputs stay in `formose/microkinetics/runs/` (git-ignored;
  regenerable via `simulate.py`).

### Git rules

* Commit only: source, tests, docs (`AGENTS.md`, `README.md`, `REPORT.md`,
  `RECORD.md`, `ACCEPTANCE.md`), input data (`formose/data/`, `molecules/`),
  scripts, configs (`para_formose.json`), and report figures
  (`formose/plots/`).
* Never commit: `formose/runs/`, `formose/tune/`,
  `formose/microkinetics/runs/`, `logs/slurm/`, `__pycache__/`,
  `*.egg-info/`, venvs, slurm logs.
* Result files under `runs/` are regenerable; their conclusions are captured
  in the committed markdown reports instead.

## Architecture (rtip_jax)

* `constants.py` - constants, Element enum, masses, covalent radii (Rust
  `STR_TO_ATOMIC_MASS` / `STR_TO_ATOMIC_RADIUS` tables).
* `config.py` - `Para` matching Rust `Para::new()` (io/input.rs).
* `system.py` - System + bond-connectivity helpers (`get_adj_mat`,
  `split_into_mol`, `judge_adj_of_mol`, `judge_variation_of_bonding`).
* `core/rtip.py` - RTI distance (quaternion) + `Rtip0PES` Gaussian bias.
* `core/idwm.py`, `core/optimization.py` - IDWM + line search.
* `pes/` - PES protocol, `RepulsivePot`, `AttractivePot`, `EvolutionPot`,
  `SynthesisPot`.
* `workflows/md.py` - `repulsive_md` and `evolution_md`, ported 1:1 from
  Rust `md.rs`.
* `workflows/pathway_sampling.py` - RTIP/IDWM pathway sampling.
* `workflows/synthesis.py` - fragment layout.
* `external/deepmd.py` - DeePMD-kit PES provider (unit conversion at the
  boundary).
* `cli.py` - `deepmd-md`, `deepmd-evolution-md`, `deepmd-pathway`,
  `mock-md`, `mock-pathway`, `synthesize`, boundary/config commands.

## Conventions

* Internal units: Bohr, Hartree, Hartree/Bohr.  XYZ files use Angstrom
  (conversion at IO boundary).  DeePMD uses eV / eV/Angstrom.
* JAX x64 enabled on import (`_config.py`).
* `System.coord` is always (natom, 3) in Bohr.
* Evolution MD amplitude: `Increasing: a_min -= a0`; `Decreasing:
  a_min += a0 * decreasing_multiple`; `Falling: a_min += a0`; bond-change
  trigger uses `judge_variation_of_bonding(..., 1.0, 1.6)`; reset at
  `a_min > a_min * decreasing_bound`.
